# CWDE Desktop Enviroment.

This is an KDE Plasma 6 Wayland fork for the AltusOS distriution.

If you don't like Wayland too much, then you can check out https://github.com/Altus-Project-Community/G-Light-X11-Enviroment .

CWDE and GLXE will both be present on the install tool with Anaconda motor.
